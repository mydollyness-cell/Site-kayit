Prompt.md

You are a senior full stack developer.

Create a simple web application for a residential site.

Context:
There are 7 apartment blocks and about 810 apartments.

Goal:
Residents will open a website and enter:
- their block
- their apartment number

Requirements:
- simple and clean interface
- mobile friendly
- store data in a database
- prevent duplicate apartment registration

Tech stack:
Frontend: HTML + CSS + JavaScript
Backend: Node.js (Express)
Database: SQLite

Features:
1. Select block (A,B,C,D,E,F,G)
2. Enter apartment number
3. Select from- drop down list.(List of vaues: 'Ev Sahibi'; 'Kiracı')
4. Enter your name and surname
5. Save registration
6. Show confirmation message

Validations:
1. Every apartment can be entered only once as 'Ev sahibi' or 'Kiracı'

Project structure:
Create a clean folder structure suitable for VSCode.

Also generate:
- index.html
- style.css
- script.js
- server.js
- database schema
